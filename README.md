I work across distributed systems, cloud infrastructure, real-time data, and developer tooling. I care about the parts that make software dependable after launch: observability, performance, fault tolerance, and clean operational workflows.

- Studying Computer Science at Georgia Tech, with a focus on AI and information internetworks.

- Contributing to open-source audio infrastructure and teaching Java and object-oriented programming.
